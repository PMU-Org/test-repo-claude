Зібрано під профіль Google Ads — uploaded display: JPEG-спрайт (WebP немає в переліку дозволених типів Google) у межах 600 КБ. Автопідбір з пріоритетом «тримати різкість» утримав 1:1, тож юридичний дисклеймер унизу креативу лишився читабельним. Спрайт запакований усередину index.html — один файл, який не зламається від часткової розпаковки.

  • delia-red-300x600.zip — пакет для Google Ads: index.html + README
  • index.html — самодостатній баннер; відкривається з будь-якої теки
  • index-with-separate-sprite.html — варіант із окремим спрайтом (на ~33% легший)
  • sprite.jpg — спрайт-аркуш, 24 кадри
  • backup.jpg — статичний backup-кадр

Збірку генерує tools/build-demo.mjs — той самий скрипт, що служить e2e-тестом конвертера.
